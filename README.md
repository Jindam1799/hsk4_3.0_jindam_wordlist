# HSK 4급 진담 짝꿍어휘 (모바일 웹 단어장)

HSK 3.0 4급 필수 어휘 1000개를 단어마다 짝꿍어휘 3개와 함께 모바일에서 볼 수 있는 웹 단어장입니다.
**덩어리로 익히면, 중국어가 툭!** — 진담중국어

## 기능
- **구간 탭**: 단어장과 같은 50개 단위 구간(0001–0050 …)으로 이동
- **검색**: 한자 · 병음(성조 없이 `anshi`도 됨) · 한국어 뜻 · 단어 번호
- **발음 듣기**: 한자나 짝꿍어휘를 누르면 중국어(여성 음성 우선)로 읽어줌
- **가리기**: `뜻 가리기` / `중국어 가리기` → 먼저 말해 보고, 가려진 부분을 눌러 확인
- **목록 / 카드 보기**: 카드 보기는 한 단어씩, 옆으로 밀어서 넘김
- **1·2·3 회독 체크**: 단어장의 박스 3개와 같은 방식. 기기(브라우저)에 저장됨

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 |
| `data.js` | 단어 데이터 (현재 0001–0010 샘플) |
| `tools/csv_to_data.py` | 엑셀(CSV) → `data.js` 변환기 |

## 단어 1000개 넣기
엑셀에서 아래 열 순서로 정리 후 **CSV UTF-8**로 저장합니다.

```
no,word,pinyin,meaning,p1,p1_pinyin,p1_ko,p2,p2_pinyin,p2_ko,p3,p3_pinyin,p3_ko
7,按时,ànshí,제때에,按时完成,ànshí wánchéng,제때에 완성하다,按时到达,ànshí dàodá,제시간에 도착하다,按时吃药,ànshí chī yào,제때에 약을 먹다
```

```
python3 tools/csv_to_data.py 단어장.csv > data.js
```

## GitHub Pages 배포
