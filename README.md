# HSK 4급 진담 짝꿍어휘 (모바일 웹 단어장)

HSK 3.0 4급 필수 어휘 1000개를 단어마다 짝꿍어휘 3개와 함께 모바일에서 볼 수 있는 웹 단어장입니다.
**덩어리로 익히면, 중국어가 툭!** — 진담중국어

## 기능
- **처음 화면 ‘이렇게 공부해요’**: 첫 방문 때 보이고, 오른쪽 위 `?` 버튼으로 다시 열 수 있음
- **단어 카드**: 단어장과 같은 구성 — 왼쪽에 번호와 체크박스 3개, 오른쪽에 단어·병음·뜻과 짝꿍어휘 ①②③
- **구간 탭 / 빨간 띠**: 50개 단위 구간(0001–0050 …), 10개마다 작은 구분선
- **검색**: 한자 · 병음(성조 없이 `anshi`도 됨) · 한국어 뜻 · 단어 번호
- **발음 듣기**: 한자나 짝꿍어휘를 누르면 중국어(여성 음성 우선)로 읽어줌
- **가리기**: `뜻 가리기` / `중국어 가리기` → 먼저 말해 보고, 가려진 부분을 눌러 확인
- **목록 / 카드 보기**: 카드 보기는 한 단어씩, 옆으로 밀어서 넘김
- **체크박스 3개**: 공부할 때마다 하나씩 체크. 기기(브라우저)에 저장됨

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 |
| `data.js` | 단어 데이터 (자동 생성 — 직접 고치지 않기) |
| `tools/words/*.txt` | 단어 원본 1000개 (200개씩 5개 파일) |
| `tools/build_data.py` | `tools/words/*.txt` → `data.js` 변환기 |

## 단어 고치기
`tools/words/` 안의 txt 파일에서 해당 줄을 고친 뒤 변환기를 실행합니다. 한 줄이 단어 하나이고, `|`로 13칸을 나눕니다.

```
번호|단어|병음|뜻|짝꿍1|병음1|뜻1|짝꿍2|병음2|뜻2|짝꿍3|병음3|뜻3
7|按时|ànshí|제때에|按时完成|ànshí wánchéng|제때에 완성하다|按时到达|ànshí dàodá|제시간에 도착하다|按时吃药|ànshí chī yào|제때에 약을 먹다
```

```
python3 tools/build_data.py
```

## GitHub Pages 배포
1. 이 파일들을 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 후 `https://<계정>.github.io/hsk4_3.0_jindam_wordlist/` 에서 열립니다.
