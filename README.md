# HSK 4급 진담 짝꿍어휘 (모바일 웹 단어장)

HSK 3.0 4급 필수 어휘 1000개를 단어마다 짝꿍어휘 3개와 함께 모바일에서 볼 수 있는 웹 단어장입니다.
**덩어리로 익히면, 중국어가 툭!** — 진담중국어

## 화면 구성
- **홈(표지)**: 단어장 표지와 같은 디자인. 캐릭터 몸에 *이어서 공부할 단어*가 나오고, 짝꿍 캐릭터 3개가 짝꿍어휘를 보여 줌. 캐릭터를 누르면 발음이 나옴
  - `이어서 공부하기` / `구간 고르기` / `공부 방법(이렇게 공부해요)`
- **공부 화면**: 한 화면에 **단어 2개**, 스크롤 없이 **왼쪽으로 밀면 다음 2개, 오른쪽으로 밀면 이전 2개**
  - 왼쪽 위 🏠 홈 버튼(휴대폰 ‘뒤로 가기’도 홈으로), 가운데 구간 띠(누르면 구간 고르기), 오른쪽 🔍 단어 찾기
  - 단어 왼쪽 체크박스 3개 = 1·2·3번 공부. 체크와 마지막으로 본 곳은 휴대폰(브라우저)에 저장
  - `뜻 가리기` / `중국어 가리기` → 먼저 말해 보고, 가린 곳을 눌러 확인
  - 화면 크기에 맞춰 글자 크기가 자동으로 조절되어, 작은 휴대폰(높이 540px)에서도 1000개 단어 모두 스크롤 없이 표시
- **발음(TTS)**: 여자 목소리 **Tingting(婷婷)** 우선 — 아이폰·아이패드·맥(사파리·크롬)은 Tingting, Tingting이 없는 PC 크롬은 구글 기본 음성(Google 普通话, 여성), 안드로이드는 기기 기본 중국어 음성. 남성 음성(Li-Mu 등)은 고르지 않음. 지금 쓰는 목소리 이름은 홈 → `공부 방법` 창에서 확인
- **카카오톡·SNS에서 링크를 열면**: 앱 안 브라우저 대신 외부 브라우저로 자동 이동 (`inapp.js`)
  - 안드로이드(카카오톡·인스타·네이버 등) → **크롬**
  - 아이폰 카카오톡 → 기본 브라우저(사파리, 또는 기본으로 설정한 크롬) / 아이폰 인스타 등 → 크롬(설치된 경우)
  - 자동 이동이 안 되면 위쪽에 `크롬으로 열기` · `링크 복사` 안내 띠가 나옴
- **링크 미리보기**: 카카오톡 등에 링크를 보내면 `og-image.png`가 미리보기 이미지로 나옴
  (주소가 `https://jindam1799.github.io/hsk4_3.0_jindam_wordlist/` 가 아니면 `index.html`의 `og:url`, `og:image` 주소를 바꿔 주세요)

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 |
| `data.js` | 단어 데이터 (자동 생성 — 직접 고치지 않기) |
| `inapp.js` | 카카오톡·SNS 앱 안 브라우저 → 크롬으로 열기 |
| `og-image.png` | 링크 미리보기 이미지 |
| `img/char.png`, `img/mini.png` | 표지 원본에서 오려 낸 캐릭터 (몸의 글자는 앱이 올림) |
| `tools/words/*.txt` | 단어 원본 1000개 (200개씩 5개 파일) |
| `tools/build_data.py` | `tools/words/*.txt` → `data.js` 변환기 |

## 단어 고치기
`tools/words/` 안의 txt 파일에서 해당 줄을 고친 뒤 변환기를 실행합니다. 한 줄이 단어 하나이고, `|`로 13칸을 나눕니다.

```
번호|단어|병음|뜻|짝꿍1|병음1|뜻1|짝꿍2|병음2|뜻2|짝꿍3|병음3|뜻3
7|按时|ànshí|제때에|按时完成|ànshí wánchéng|제때에 완성하다|按时到达|ànshí dàodá|제시간에 도착하다|按时吃药|ànshí chī yào|제때에 약을 먹다
```

```
python3 tools/build_data.py
```

## GitHub Pages 배포
1. 이 파일들을 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 후 `https://<계정>.github.io/hsk4_3.0_jindam_wordlist/` 에서 열립니다.
